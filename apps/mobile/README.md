# apps/mobile

Expo (React Native, TypeScript) shell for Prasm on Solana Mobile Seeker.

## Run

```
cd apps/mobile
npm install
npx expo start
```

## Screens (placeholders)

- **Home**: daily goal, streak, XP (local stubs)
- **Paths**: six path titles only; lesson content lives in the private `Prasm-content` repo
- **Wallet**: Connect / Disconnect wired to a stub that reports unavailable (MWA later)

No trading, no signing, no custody. All UI strings: English.
